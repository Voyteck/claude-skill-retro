# Cross-project lessons

One place for knowledge that applies to more than one project: pitfalls of this computer, its shells, tools,
accounts and services. Project memory loads only in that project's folder, so a lesson stored only there tends to
be broken in another project. Rules (what we do) live in `~/.claude/CLAUDE.md`; this file holds knowledge (why
and how).

Add each new lesson with a date and evidence (session, commit, PR). Project memories do not duplicate this
content; at most they point here.
